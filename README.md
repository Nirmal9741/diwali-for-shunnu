# 🪔 Happy Diwali, Shunnu! ❤️

A special interactive Diwali celebration web experience crafted with love by **Munnu** for **Shunnu**.

✨ **Live Link**: [https://nirmal9741.github.io/diwali-for-shunnu/](https://nirmal9741.github.io/diwali-for-shunnu/)

---

### 🌟 Features
- 🪔 **Interactive Diya Lighting**: Tap to light the diya and illuminate the night sky with lanterns and fireworks.
- 🎶 **Procedural Romantic Music**: Soothing melody generated live via Web Audio API.
- 📖 **Our Journey Story**: An animated story recap from the first random hello, late-night talks, meeting in Chandigarh, cooking together, to celebrating Diwali together.
- 💖 **Floating Hearts & Fireworks**: Touch-responsive bursting sparklers and lanterns.
